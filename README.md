# Excel for Data Analytics

## About
This repository showcases my learning journey in Microsoft Excel for data analytics, including data cleaning, data manipulation, formulas, PivotTables, and data visualization.

## Skills Covered
- **Data Cleaning:** Removing duplicates, handling missing values, and formatting data.
- **Excel Functions:** SUM, AVERAGE, IF, COUNTIF, SUMIF, VLOOKUP, and XLOOKUP.
- **Data Analysis:** Sorting, filtering, conditional formatting, and trend analysis.
- **PivotTables:** Summarizing and comparing datasets.
- **Data Visualization:** Charts, graphs, and dashboards.

## Tools Used
- Microsoft Excel
- Excel Formulas and Functions
- PivotTables and PivotCharts

## Project Goals
- Develop practical data analysis skills.
- Transform raw data into meaningful insights.

- Build a portfolio for data analyst opportunities.
